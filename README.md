# 競馬コースノート 東京データ版 v0.2

`course-data.json` に東京競馬場の共通知識と芝6・ダート4の計10距離コースを登録しています。

## GitHubへの反映

ZIPを解凍し `keiba-pwa` フォルダ内の8ファイル（`course-data.json` を含む）をGitHubリポジトリのルートにアップロードしてCommit。既存ファイルを上書きします。GitHub Pagesが更新されたら再読み込みしてください。

## 注意

JRA確認済みのコース構造と、ユーザー提供の予想仮説は異なります。枠順・脚質・ローテーションの優劣は集計条件を確認するまで断定しないでください。

MacとiPhoneの個人メモは自動同期されません。既に端末で同じコースのメモを保存している場合は、その保存内容が公開JSONより優先されます。

出典（構造）：https://www.jra.go.jp/facilities/race/tokyo/course/
