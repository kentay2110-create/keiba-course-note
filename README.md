# 競馬コースノート（初版）

## 機能
- 10競馬場・芝/ダート・距離を指定し、コースごとの個人メモを保存
- 東京・芝1600mの初期サンプル情報を収録（他コースは未登録。推測情報を表示しません）
- ワイド・馬連・馬単・3連複・3連単の全組み合わせ数と等確率モデルの参考値
- JSON形式のメモのバックアップ・復元
- Service Workerによるオフライン対応

## GitHub Pagesへの公開（無料）
1. GitHubで **Public** リポジトリを作成（例: `keiba-note`）。
2. このフォルダの **中身** をリポジトリの最上位にアップロード。
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
4. 公開された `https://ユーザー名.github.io/keiba-note/` をiPhoneのSafariで開き、共有→ホーム画面に追加。
5. 必要なファイルの読み込みが終わったらオフライン利用できます。

## 注意
- `index.html`をMacのファイルとして直接開くと、Service Workerが動きません。HTTPSのGitHub Pagesなどで公開してください。
- 無料GitHub Pagesの公開リポジトリではソースコードが一般公開されます。メモはブラウザ内保存で、サーバーには自動送信しません。
- ブラウザデータ削除・端末変更に備え、定期的にJSONをバックアップしてください。
- コースの距離選択肢は汎用リストで、選択した全組み合わせについて実際のレースが施行されるとは限りません。
- コースの公式情報と枠順・脚質の統計傾向は今後追加する予定です。現時点で根拠のない傾向を自動表示しません。
- ワイドの複数点購入時の参考的中確率は近似値です。
