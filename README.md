# 競馬コースノート v0.3（東京＋京都）

東京10コース・京都16コース（芝の内回り・外回りを区別）を `course-data.json` に収録。

## 更新方法

ZIPを解凍し、8ファイルをGitHub Pages対象のリポジトリのルートにアップロードして上書き、Commit。

## 注意

京都芝1400m・1600m・2000mは、内回り・外回りを別選択。競走当日の正式なコース指定を確認してください。

コースの客観的構造はJRA公式サイト（https://www.jra.go.jp/facilities/race/kyoto/course/ ）で確認。枠順・脚質・血統・騎手に関する数値や有利不利はユーザー提供の予想仮説をベースにし、未検証と明記。

メモは端末のローカルストレージに保存。過去に保存したメモが初期登録情報に優先するため、更新後も古いメモが出る場合があります。バックアップのエクスポートを推奨。
